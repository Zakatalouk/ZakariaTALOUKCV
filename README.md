# Zakaria Talouk — Personal CV website

A lightweight, responsive, single-page portfolio built with semantic HTML, CSS and a small amount of JavaScript. The project uses no build step or third-party JavaScript dependencies.

## Run locally

From this directory, run:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>. The page can also be hosted as a static site by uploading this folder to GitHub Pages, Netlify or Cloudflare Pages. Keep `assets/zakaria-talouk-cv.pdf` in place so the CV download works.

## Content and assets

The page content is based on the provided English CV and the more detailed French CV. Project artwork is made from CSS and typography because no portfolio images were supplied. The downloadable CV is the original PDF. The supplied portrait is included as an optimized JPEG in `assets/zakaria-talouk-portrait.jpg`.
